# Users and Admin

The first account made on an instance is the admin. It is the only account that can manage the others.

## What an Admin Can Do

From the admin screen:

- Add an account: they get a password you set, and are asked to change it the first time they sign in.
- Reset a password: same again, the new one has to be changed on next sign-in.
- Reset someone's progress: clears their section progress and quiz attempts without touching their courses.
- Delete an account: takes their courses, progress, attempts and graph with it.
- Open someone's knowledge graph: the one view that reaches across accounts.

## What an Admin Cannot See

The knowledge graph is the only thing an admin can open on someone else's behalf. There is no way to read another person's notebook, their courses, or their quiz answers. The admin screen shows how many courses each account has made, and that is the extent of it.

Even the graph is read-only there. Forgetting a concept is hidden when viewing someone else, because that action only ever applies to your own rows.

## What Stays Private

Everything is per person. Courses, progress, quiz attempts and the knowledge graph all belong to the account that made them, and nothing is pooled across the instance.

## Provider Keys

An instance-wide provider connection can be set so nobody has to bring their own key. Individual accounts can still connect their own, which takes precedence over the instance one.
