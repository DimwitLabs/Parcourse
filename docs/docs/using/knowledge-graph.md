# Knowledge Graph

The knowledge graph is what every course you have taken adds up to. It is not a streak or a count of hours; it maps what you have covered and how the pieces relate.

## Tiers

Concepts sit at four levels, each belonging to the one above it:

| Tier | What it holds |
| --- | --- |
| Domain | The broadest grouping |
| Field | A discipline within a domain |
| Topic | A subject within a field |
| Skill | Something specific you can do |

A course contributes concepts at whichever tiers fit it, and concepts are shared between courses, so a second course on the same subject deepens what is there rather than adding a parallel copy.

## Mastery

Each concept carries a score. It reads as **new**, **learning** or **mastered**, and mastered begins at 0.9, the same line a quiz calls mastery.

## Forgetting a Concept

A concept can be dropped from your graph. Clicking one brings up the option, and forgetting asks first, every time.

Forgetting a concept takes everything below it that has nothing else holding it up. A topic without its field has nothing left to hang from, so it goes too. A concept that also belongs to one you are keeping stays where it is. The confirmation names everything that will go before it goes.

A forgotten concept comes back if another course teaches it.

## Exporting

The graph exports as an SVG or a PNG with a transparent background, so it sits on whatever you drop it into, and it is drawn light whichever theme you exported it from.
