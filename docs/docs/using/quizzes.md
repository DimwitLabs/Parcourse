# Quizzes

Every course has one quiz, written over the whole course rather than one per section. It mixes two kinds of question.

## The Two Kinds

**Multiple choice** questions have one right answer and an explanation that is shown once you have submitted, so a wrong answer teaches something rather than just costing a mark.

**Written answers** are marked by the model against a reference answer. They can score in halves, which is why a total sometimes reads as rounded.

## Scoring

Scores are shown rounded to whole marks. When rounding actually changed the number, the page says what was really scored rather than hiding it.

| Score | What it means |
| --- | --- |
| 90% or above | Mastery. The knowledge graph marks the course's concepts mastered at the same line. |
| 70% or above, with every section marked done | The course counts as passed and shows as finished in the notebook. |

Both use the same 0.9, so passing a quiz and mastering a concept mean one thing rather than two similar ones.

## Attempts

A quiz can be taken more than once, and every attempt is kept. The history page lists them newest first and marks the point at which you first reached mastery.

An attempt in progress is saved as a draft, so closing the tab does not lose the answers you have already written.
