# Learning Styles

Not everyone wants to be asked the same way. A learning style sets the kind of questions every course asks you, and how much they challenge you. The video, the sections, the summaries and the cheatsheet stay the same whichever style you pick.

## The Styles

| Style | What it is like |
| --- | --- |
| <LearningStyle style="explorer" /> | An easygoing check-in after each part. Offers a balance of different questions. |
| <LearningStyle style="quick_study" /> | Fast checks that keep you moving. Offers only choice-based questions. |
| <LearningStyle style="deep_diver" /> | Questions that make you think things through. Offers mostly written questions. |
| <LearningStyle style="storyteller" /> | Explain what you watched in your own words. Offers only written questions. |
| <LearningStyle style="practitioner" /> | Quick checks, with a moment to reflect. Offers mostly choice-based questions. |
| <LearningStyle style="exam_ready" /> | The toughest workout before a test. Offers the most questions of both kinds. |

## Picking One

**Settings** opens on **Learning Style**. Pick a style and save it, and every course you make from then on uses it. Courses you already have keep the style they were made with.

Each person on an instance picks their own, so two people making a course from the same video can be quizzed in different ways.

## Changing One Course

Regenerating a course lets you switch its style for that course alone. The dropdown starts on the course's current style; pick another and saying what was wrong becomes optional, since the new style is reason enough. Your default in **Settings** does not change.

The [browser extension](/using/extension) can do the same for a course it starts: its popup has a switcher that stays on your default unless you change it.

The style a course was made with shows as a pill beside **Sections** on the course page, and on its card on the home screen and in the notebook.

Regenerating rebuilds the whole course, so quiz answers, scores and progress are cleared, as they are for any regeneration. See [Regenerating and Deleting](/using/courses#regenerating-and-deleting).
